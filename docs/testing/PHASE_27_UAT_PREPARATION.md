**Expected Home (`verify` stage; checked on a scratch database with Asia/Manila):**
- **staff:**
  - greeting "Uat Staff"; UAT27 Field Technician / UAT27 Operations;
  - Today (3), in order:
    1. `[UAT27] Replace filter unit` (task, all day);
    2. `[UAT27] Site visit — Acme` 09:00–10:30;
    3. `[UAT27] Team meeting` 14:00–15:00;
  - tasks: open 2 / overdue 1 / due today 1;
  - messages: 1 unread; notifications: 1 unread;
  - announcements: none before `announce`, then `[UAT27] Office closed Friday`;
  - no colleague item appears.
- **empty:** Today 0; tasks 0/0/0; messages 0; notifications 0; announcements none (before `announce`).
- **manager:** Today = `[UAT27] Manager own task` only; tasks 1/0/1. Nothing from the staff member or colleague appears.
- **admin:** Today = `[UAT27] Admin own task` only; tasks 1/0/1.
- **admin_noprofile:** no-profile variant (staff/today/tasks/messages/announcements are null); only notifications are shown.

**Constraints:**
- UAT-27-03's "no announcements" empty state requires that **no** published company-wide (or UAT27-scoped) announcement is visible. The `plan` stage reports the count of pre-existing non-UAT27 published company-wide announcements; if it is not 0, that part of UAT-27-03 cannot be observed without altering existing data. Report it rather than changing that data.
- "Today" is relative. Run `seed` **on the UAT day (Manila)**, and re-run it if UAT crosses Manila midnight. Re-running is idempotent: it never re-creates accounts, never prints passwords again, moves the dated records to the new day, and resets staff to exactly 1 unread message and 1 unread notification.
- Publishing an announcement through the Admin API fans out notifications to all users, including the UAT27 accounts. Use only the `announce` stage during UAT.

## 6. Script — `uat27_data.php`

SHA-256 of the exact text below, saved with a trailing newline: see `docs/testing/TEST_STATUS.md` (Phase 27 final UAT preparation).

```php
<?php

/*
 * Phase 27 UAT data — operator tool (NOT application code; never commit to
 * apps/api, never expose over HTTP).
 *
 * Run inside the staging `app` container, reading this file from stdin:
 *
 *   $C exec -T app php -- <stage> < uat27_data.php
 *
 * Stages:
 *   plan      read-only: company day, existing UAT27 accounts, pre-existing
 *             visible company-wide announcements
 *   seed      idempotent: UAT27 accounts/profiles + UAT-27-02 data dated to
 *             the CURRENT company day (Asia/Manila). Re-run on the UAT day.
 *             Prints a generated password ONCE for each newly created account.
 *   announce  publishes the one company-wide UAT27 announcement (run AFTER
 *             UAT-27-03, whose empty state needs no visible announcement)
 *   verify    read-only: runs the real GET /me/home controller for each UAT27
 *             account and prints a summary of what Home will show
 *
 * Only records prefixed "UAT27" / "[UAT27]" or UAT27 accounts are created
 * or changed. No truncation, no migrations, no existing business data edited.
 */

use App\Enums\AccountStatus;
use App\Enums\AnnouncementAudienceType;
use App\Enums\AnnouncementStatus;
use App\Enums\ConversationType;
use App\Enums\NotificationSourceType;
use App\Enums\NotificationType;
use App\Enums\ScheduleEntryActivityType;
use App\Enums\StaffStatus;
use App\Enums\TaskStatus;
use App\Http\Controllers\Api\V1\Home\MyHomeController;
use App\Models\Announcement;
use App\Models\Conversation;
use App\Models\Department;
use App\Models\Notification;
use App\Models\Position;
use App\Models\Role;
use App\Models\ScheduleEntry;
use App\Models\Staff;
use App\Models\Task;
use App\Models\User;
use App\Support\CompanyTimezone;
use App\Support\Reporting\OverdueTasks;
use Illuminate\Contracts\Console\Kernel;
use Illuminate\Http\Request;
use Illuminate\Support\Carbon;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Hash;
use Illuminate\Support\Str;

require getcwd().'/vendor/autoload.php';
$app = require getcwd().'/bootstrap/app.php';
$app->make(Kernel::class)->bootstrap();

$stage = $argv[1] ?? 'plan';

// key => [email, user name, role, staff profile [employee_number, first, last] or null]
$accounts = [
    'staff' => ['uat27.staff@company-app.test', 'UAT27 Staff', Role::STAFF, ['UAT27-001', 'Uat', 'Staff']],
    'colleague' => ['uat27.colleague@company-app.test', 'UAT27 Colleague', Role::STAFF, ['UAT27-002', 'Uat', 'Colleague']],
    'empty' => ['uat27.empty@company-app.test', 'UAT27 Empty', Role::STAFF, ['UAT27-003', 'Uat', 'Empty']],
    'manager' => ['uat27.manager@company-app.test', 'UAT27 Manager', Role::MANAGER, ['UAT27-004', 'Uat', 'Manager']],
    'admin' => ['uat27.admin@company-app.test', 'UAT27 Admin', Role::ADMINISTRATOR, ['UAT27-005', 'Uat', 'Admin']],
    'admin_noprofile' => ['uat27.admin.noprofile@company-app.test', 'UAT27 Admin No-Profile', Role::ADMINISTRATOR, null],
];

$tz = CompanyTimezone::value();
$day = OverdueTasks::todayInCompanyTimezone(); // Y-m-d in the company timezone
$at = fn (string $time, int $dayOffset = 0) => Carbon::parse($day.' '.$time, $tz)->addDays($dayOffset)->utc();
$dueDate = fn (int $dayOffset = 0) => Carbon::parse($day, $tz)->addDays($dayOffset)->toDateString();

echo "stage={$stage} company_timezone={$tz} company_date={$day} utc_now=".now('UTC')->toIso8601String().PHP_EOL;

$users = fn () => collect($accounts)->map(fn ($a) => User::query()->where('email', $a[0])->first());

if ($stage === 'plan') {
    foreach ($users() as $key => $user) {
        echo str_pad($key, 16).($user ? "exists (status={$user->status->value}, staff=".($user->staff ? 'yes' : 'no').')' : 'absent').PHP_EOL;
    }
    $visible = Announcement::query()
        ->where('status', AnnouncementStatus::Published->value)
        ->where('audience_type', AnnouncementAudienceType::CompanyWide->value)
        ->where('title', 'not like', '[UAT27]%')
        ->count();
    echo "pre-existing published company-wide announcements (non-UAT27): {$visible}".PHP_EOL;
    echo 'roles present: '.Role::query()->whereIn('name', [Role::ADMINISTRATOR, Role::MANAGER, Role::STAFF])->count().'/3'.PHP_EOL;
    exit(0);
}

if ($stage === 'seed') {
    DB::transaction(function () use ($accounts, $at, $dueDate) {
        $department = Department::query()->firstOrCreate(['name' => 'UAT27 Operations'], ['description' => 'Phase 27 UAT only']);
        $position = Position::query()->firstOrCreate(
            ['department_id' => $department->id, 'title' => 'UAT27 Field Technician'],
            ['description' => 'Phase 27 UAT only'],
        );

        $staff = [];
        foreach ($accounts as $key => [$email, $name, $roleName, $profile]) {
            $user = User::query()->firstOrNew(['email' => $email]);
            $isNew = ! $user->exists;
            $user->name = $name;
            $user->role_id = Role::query()->where('name', $roleName)->value('id');
            $user->status = AccountStatus::Active;
            if ($isNew) {
                $password = Str::password(20, symbols: false);
                $user->password = Hash::make($password);
                echo "NEW ACCOUNT {$email} password: {$password}   <- store securely; shown once".PHP_EOL;
            }
            $user->save();

            if ($profile !== null) {
                [$number, $first, $last] = $profile;
                $staff[$key] = Staff::query()->updateOrCreate(['employee_number' => $number], [
                    'first_name' => $first,
                    'last_name' => $last,
                    'status' => StaffStatus::Active,
                    'department_id' => $department->id,
                    'position_id' => $position->id,
                    'user_id' => $user->id,
                ]);
            }
        }

        // The manager manages the UAT staff member, so any team/manager-wide
        // leakage on the manager's Home (UAT-27-08) would be visible.
        $staff['staff']->update(['manager_id' => $staff['manager']->id]);
        $staff['colleague']->update(['manager_id' => $staff['manager']->id]);

        $entry = function (Staff $creator, string $title, ScheduleEntryActivityType $type, Carbon $start, Carbon $end, array $participants = []) {
            $e = ScheduleEntry::query()->firstOrNew(['creator_staff_id' => $creator->id, 'title' => $title]);
            $e->fill(['activity_type' => $type, 'starts_at' => $start, 'ends_at' => $end, 'is_all_day' => false])->save();
            $e->participants()->syncWithoutDetaching(collect($participants)->pluck('id')->all());
        };
        $task = function (Staff $assignee, string $title, TaskStatus $status, string $due) {
            $t = Task::query()->firstOrNew(['assignee_staff_id' => $assignee->id, 'title' => $title]);
            $t->fill(['status' => $status, 'priority' => 'normal', 'due_date' => $due, 'completed_at' => null])->save();
        };

        // UAT-27-02 — the UAT staff member's own data (company day, Asia/Manila times).
        $entry($staff['staff'], '[UAT27] Site visit — Acme', ScheduleEntryActivityType::ClientVisit, $at('09:00'), $at('10:30'));
        $entry($staff['colleague'], '[UAT27] Team meeting', ScheduleEntryActivityType::Meeting, $at('14:00'), $at('15:00'), [$staff['staff']]);
        $task($staff['staff'], '[UAT27] Replace filter unit', TaskStatus::InProgress, $dueDate(0));
        $task($staff['staff'], '[UAT27] Submit service report', TaskStatus::Todo, $dueDate(-3));

        // UAT-27-02 isolation — another employee's entry and tasks, same day.
        $entry($staff['colleague'], '[UAT27] Colleague-only visit', ScheduleEntryActivityType::ClientVisit, $at('11:00'), $at('12:00'));
        $task($staff['colleague'], '[UAT27] Colleague task (must not show for UAT27 Staff)', TaskStatus::Todo, $dueDate(0));
        $task($staff['colleague'], '[UAT27] Colleague overdue task', TaskStatus::Todo, $dueDate(-2));

        // UAT-27-08 — each elevated profile has exactly one own task due today.
        $task($staff['manager'], '[UAT27] Manager own task', TaskStatus::Todo, $dueDate(0));
        $task($staff['admin'], '[UAT27] Admin own task', TaskStatus::Todo, $dueDate(0));

        // UAT-27-02 — one unread direct message from the colleague, created the
        // way MessageController::store does (sender marked read + the same
        // message_received notification for the recipient). Earlier seeded
        // messages are marked read first, so exactly one is unread.
        $conversation = Conversation::query()
            ->where('type', ConversationType::Direct)
            ->whereHas('members', fn ($q) => $q->where('staff_id', $staff['staff']->id))
            ->whereHas('members', fn ($q) => $q->where('staff_id', $staff['colleague']->id))
            ->first();
        if ($conversation === null) {
            $conversation = Conversation::create(['type' => ConversationType::Direct]);
            $conversation->members()->createMany([['staff_id' => $staff['staff']->id], ['staff_id' => $staff['colleague']->id]]);
        }
        $latestId = $conversation->messages()->max('id');
        $conversation->members()->where('staff_id', $staff['staff']->id)->update(['last_read_message_id' => $latestId]);
        Notification::query()->where('recipient_user_id', $staff['staff']->user_id)->whereNull('read_at')->update(['read_at' => now()]);

        $message = $conversation->messages()->create([
            'sender_staff_id' => $staff['colleague']->id,
            'body' => '[UAT27] Hi — can you confirm the Acme visit time?',
        ]);
        $conversation->members()->where('staff_id', $staff['colleague']->id)->update(['last_read_message_id' => $message->id]);
        Notification::create([
            'recipient_user_id' => $staff['staff']->user_id,
            'type' => NotificationType::MessageReceived,
            'title' => 'New message',
            'message' => 'You have a new message in one of your conversations.',
            'source_type' => NotificationSourceType::Conversation,
            'source_public_id' => $conversation->public_id,
        ]);
    });
    echo 'seed: done'.PHP_EOL;
    exit(0);
}

if ($stage === 'announce') {
    $admin = User::query()->where('email', $accounts['admin'][0])->firstOrFail();
    $a = Announcement::query()->firstOrNew(['title' => '[UAT27] Office closed Friday']);
    $a->fill([
        'body' => 'Phase 27 UAT announcement.',
        'status' => AnnouncementStatus::Published,
        'audience_type' => AnnouncementAudienceType::CompanyWide,
        'published_at' => $a->published_at ?? now(),
        'created_by_user_id' => $admin->id,
        'published_by_user_id' => $admin->id,
    ])->save();
    echo "announce: {$a->public_id} published_at=".$a->published_at->toIso8601String().PHP_EOL;
    exit(0);
}

if ($stage === 'verify') {
    foreach ($users() as $key => $user) {
        if ($user === null) {
            echo "{$key}: absent".PHP_EOL;

            continue;
        }
        $request = Request::create('/api/v1/me/home', 'GET');
        $request->setUserResolver(fn () => $user);
        $d = app(MyHomeController::class)->show($request)->getData(true)['data'];
        $s = $d['staff'];
        echo "== {$key} ({$user->email}) role={$d['user']['role']} day={$d['company_day']['date']}{$d['company_day']['utc_offset']}".PHP_EOL;
        echo '   staff: '.($s === null ? 'none (no-profile variant)' : "{$s['display_name']} / ".($s['position']['title'] ?? '—').' / '.($s['department']['name'] ?? '—')).PHP_EOL;
        if ($d['today'] !== null) {
            echo "   today total={$d['today']['total_count']}: ".collect($d['today']['items'])->map(fn ($i) => "{$i['source_type']}:{$i['title']}")->implode(' | ').PHP_EOL;
            echo "   tasks open={$d['tasks']['open_count']} overdue={$d['tasks']['overdue_count']} due_today={$d['tasks']['due_today_count']}; messages unread={$d['messages']['unread_count']}".PHP_EOL;
            echo '   announcements: '.(collect($d['announcements']['latest'])->pluck('title')->implode(' | ') ?: '(none)').PHP_EOL;
        }
        echo "   notifications unread={$d['notifications']['unread_count']}".PHP_EOL;
    }
    // For UAT-27-04: the direct conversation the colleague posts into.
    $ids = $users()->only(['staff', 'colleague'])->filter()->map(fn ($u) => $u->staff?->id);
    $conversation = $ids->count() === 2 ? Conversation::query()
        ->where('type', ConversationType::Direct)
        ->whereHas('members', fn ($q) => $q->where('staff_id', $ids['staff']))
        ->whereHas('members', fn ($q) => $q->where('staff_id', $ids['colleague']))
        ->first() : null;
    echo 'UAT-27-04 conversation public_id: '.($conversation->public_id ?? '(not seeded)').PHP_EOL;
    exit(0);
}

fwrite(STDERR, "unknown stage: {$stage}\n");
exit(1);
```
